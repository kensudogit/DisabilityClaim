# 見積り WBS（人日）

単位は人日。小/中/大は経験則のレンジ。制度仕様が未提供の項目にはリスクバッファを別掲する。

## 凡例

| 規模 | 人日レンジ |
|------|------------|
| 小 | 3〜8 |
| 中 | 8〜20 |
| 大 | 20〜45 |

## MVP vs 本番完全版

| 観点 | MVP | 本番完全版 |
|------|-----|------------|
| 利用者/受給者証 | CRUD + 一覧/詳細 | 履歴・重複期間UI・権限細分化 |
| Excel移行 | ステージング検証 | 複数帳票・差分再取込・突合レポート |
| 月次抽出 | 候補抽出〜バッチ | 取消・再請求・市町村再生成 |
| 計算 | Engine骨格 + null安全 | 全加算/逓減/Golden Master一致 |
| Validation | 主要 ERROR | 返戻コード連動・全ルール |
| 国保連出力 | Adapter interface のみ | 公式I/F完全実装・取込受入 |
| 障害児 | category 分離 | 個別 Rule Set 全面 |
| 監査/権限 | ログイン + 基本RBAC | 完全監査・エクスポート制御 |
| テスト | API/主要画面 | Testcontainers + Playwright + 並行稼働 |

### 人日レンジ（合算目安）

| スコープ | 合計目安（人日） |
|----------|------------------|
| MVP（仕様調査・骨格含む） | 約 90〜160 |
| 本番完全版（MVP含む積み上げ） | 約 220〜400 |
| リスクバッファ（下記） | +20%〜40% |

## リスクバッファ（未提供の国保連I/F・報酬告示）

| リスク | 影響 | バッファ目安 |
|--------|------|--------------|
| 国保連/電子請求I/F仕様未提供 | Exporter・Golden Master・E2E出力が完成不可 | +15〜30人日、または完全版の出力工程を別契約 |
| 報酬告示・加算・逓減の公式資料不足 | 計算一致検証不可 | +20〜40人日（Rule実装・再テスト） |
| Excel列意味の曖昧さ | 移行再作業 | +5〜15人日 |
| 返戻サンプル不足 | Validationの抜け | +5〜10人日 |

**方針**: 仕様未提供のまま「完成」扱いにしない。Adapter/DTO/テスト骨格までをMVP完了条件とし、実レイアウト実装は仕様受領後スプリントに分離する。

## 前提（Assumptions）

- 送信は国提供の取込送信システム経由（本システムはファイル生成まで）
- バックエンドは Java 21+ / Spring Boot 3 / PostgreSQL 16
- フロントは Next.js 15 / React 19
- 個人情報は匿名化または最小権限で扱う
- 対象は計画相談支援・障害児相談支援（他サービスは対象外）

## スコープ外（Out of scope）

- 国保連への直接オンライン送信
- 報酬単位・加算値・逓減閾値の推測実装
- 介護保険・他障害福祉サービスの包括請求
- 公式仕様書の代わりとなる非公式ブログ根拠のロジック確定
- 本番個人情報を含むテストデータのリポジトリ格納
