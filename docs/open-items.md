# 公式資料・未確定事項チェックリスト

本番の計算・国保連出力を完成扱いする前に、以下を揃えること。

## 必須（計算・Validation）

- [ ] 対象請求年月に有効な報酬告示
- [ ] 留意事項・解釈通知・Q&A
- [ ] 計画相談支援のサービスコード表
- [ ] 障害児相談支援のサービスコード表
- [ ] 加算マスタ（コード・名称・単位・適用条件・適用期間）
- [ ] 減算・排他（同時算定不可）ルール
- [ ] 担当件数逓減の公式ルール（閾値・集計単位・算定順）
- [ ] 地域区分・単価（単位単価）表
- [ ] 端数処理ルール

## 必須（国保連出力）

- [ ] 電子請求受付システム / 国保連向けインタフェース仕様書（対象年度版）
- [ ] レコードレイアウト・必須項目・桁数・文字コード・レコード順
- [ ] コード体系（市町村・サービス・負担など）
- [ ] 制御レコード（件数・合計・checksum 等）の要否
- [ ] 取込送信システムでの受入テスト手順とサンプル

## 業務・移行

- [ ] 現行 Excel 一式と各列の意味（必須/任意）
- [ ] 月次請求業務フロー（As-Is）
- [ ] 正常請求サンプル（匿名化）
- [ ] 返戻サンプル（匿名化）と返戻理由コード
- [ ] 利用している加算の事業所実績一覧
- [ ] 逓減の現行計算例

## 非機能

- [ ] 個人情報・監査・バックアップ・保管期間要件
- [ ] ロール（誰が確定・出力できるか）
- [ ] 並行稼働期間と突合方法

## 注意

仕様が揃うまで、報酬値のハードコードや国保連ファイルレイアウトの推測実装は行わない。
