# disability-consultation-billing

障害福祉サービス（相談支援）事業所向け請求業務システムを Java + Spring Boot + PostgreSQL + React + Next.js + TypeScript で開発するためのClaude Code向けSkillです。

## 導入
Claude CodeのSkillsディレクトリ配下に、このフォルダを **フォルダ名を変更せず** 配置してください。

フォルダ名: `disability-consultation-billing-skill`

SKILL.md の name: `disability-consultation-billing`

環境によってフォルダ名とnameの一致を要求する場合は、フォルダ名を `disability-consultation-billing` に変更して配置してください。本ZIPでは互換性を優先し、同名版ZIPも同梱生成できます。

## 使い方例
- 「このSkillに従ってER図とDDLを作成して」
- 「Excel初期移行機能をSpring Bootで実装して」
- 「2026年8月請求のCalculation Engineの設計を作って」
- 「国保連仕様書を渡すのでKokuhoExportAdapterを実装して」
- 「返戻防止Validation RuleをJUnit付きで実装して」

## 必要資料
本番用Exporterを完成させるには、対象年度・請求年月に対応した公式の国保連/電子請求受付システム関連仕様書、サービスコード等のマスタ、報酬算定資料が必要です。
